React Learning

A collection of React exercises and small learning projects developed while learning modern frontend development.

Purpose

This repository contains my weekly React practice, experiments, and exercises.

The goal is to strengthen my understanding of:

- React fundamentals
- Components and props
- State and events
- Hooks
- Working with APIs
- Forms and user interactions
- Reusable UI patterns
- Modern frontend development

> These projects are learning exercises and are not presented as production portfolio projects.
